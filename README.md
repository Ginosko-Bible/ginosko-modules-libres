# ginosko-modules-libres

Modules bibliques dont la fiche indique le **domaine public**, pour [Ginosko Bible](https://github.com/Ginosko-Bible/ginosko-bible) : Bibles (Darby, Louis Segond, Ostervald, KJV), commentaires (Henry, Clarke, Barnes, Gill, Wesley, JFB, Scofield, TSK, Meyer), dictionnaires (Easton, Fausset, ISBE, Smith, Scofield) et lexique grec (Thayer).

- Format : modules e-Sword (SQLite : `.bbli`, `.cmti`, `.dcti`, `.lexi`).
- `manifeste.json` : taille, sha256 et licence de chaque fichier. `ATTRIBUTIONS.md` : titre et mention de chaque fiche.
- Validation par l'administrateur le 2026-11-12.

## Licence : à lire

Le tri est **indicatif, ce n'est pas un avis juridique** : il repose sur la mention « public domain » de la fiche de chaque module et sur l'année de publication de l'œuvre d'origine. La mise en forme du module (numérotation, balises) peut avoir ses propres conditions. L'ISBE (édition de 1939) a été signalé comme point à vérifier.

Si vous êtes titulaire de droits sur l'un de ces fichiers et souhaitez son retrait, ouvrez une « issue » : il sera retiré rapidement.

Les modules reconstruits (LSG+, Ostervald+, KJV+), les notes personnelles et les études ne sont **jamais** dans ce dépôt.
